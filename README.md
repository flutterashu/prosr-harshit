# ProSR — Progressive Social Responsibility (v2)

A fully rebuilt, modern multi-page website for PSR.

## What's new in v2
- Fresh editorial + impact-driven design system (Fraunces + Inter typography)
- Animated impact counters
- Case studies section
- Client logos strip
- Auto-playing testimonials carousel
- FAQ accordion (Services page)
- Interactive lifecycle timeline (Approach page)
- Insights / blog section with 6 placeholder posts
- Working contact form with client-side validation + mailto fallback
- Full keyboard accessibility & reduced-motion support
- SEO-friendly directory slug URLs, sitemap and robots.txt
